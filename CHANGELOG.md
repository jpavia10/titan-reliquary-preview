## How this branch relates to the real pipeline

The published site is **generated output** of Joseph's `publish_all.sh` (runs on his
own machine at `/home/box/collection/gui/publish_all.sh`, which I do not have).
The app repo is not editable source data — `data/index.json`, `data/detail/`,
`version.json`, and the photo shards change dynamically at publish time.

- I **read** `data/index.json` / `version.json` to build the UI against real fields
  (`value.estimated_total`, `counts.*`, `photos.*`, `albums_glance[]`, `vault.moments[]`),
  but **never committed or altered** them. They are fetched at runtime exactly as before.
- The `?v=` cache-bust stamps in `index.html` and `version.json`'s `content_hash`
  are normally regenerated by `publish_all.sh`. Because this branch edits
  `styles.css` / `app.js`, I set a **local stamp `?v=theme-refresh-2`** on the
  `<link>`, `<script>` tags and `window.TITAN_BUILD`, and the same string as the
  service worker `BUILD`. **On merge, `publish_all.sh` must regenerate its own
  stamps as usual — do not keep `theme-refresh-2` in production.**
- New static assets (fonts, `js/playlist.js`, `audio.js`, `ambient.js`,
  `favicon.svg`) live **outside** `data/` so the publish pipeline cannot clobber them.
- `DRIVE_ANALYSIS.md` at the repo root is untracked review context from this
  morning's Drive analysis — not part of the theme work. Delete or keep at Joseph's call.

## What changed (file by file)

### `index.html`
- Added an inline `<script>` in `<head>` (before `styles.css` loads) that reads
  `localStorage.tr_theme_v1` and sets `data-theme` on `<html>` — no flash of the
  wrong theme on load/reload.
- Added a 3-way segmented theme toggle (Vault / Ledger / Noir) and a Rain button
  (inline SVG cloud icon) in the header actions, next to the Auto toggle.
- Added `favicon.svg` link (new file, gold-coin mark on dark).
- Replaced the board pane's empty shell and the "Loading vault…" header text with
  skeleton shimmer blocks (rendered until `app.js` replaces them with real data).
- Added `<script>` tags for `js/playlist.js`, `audio.js`, `ambient.js`.
- `?v=` stamps: `3f0bd0c319f0ef31` → `theme-refresh-2` (see stamp note above).

### `styles.css`
- New CSS variables for previously hardcoded surfaces (`--th-bg`, `--tabgrad1/2`,
  `--foot-bg`, `--ph-bg`, `--sel-bg`, `--hold-bg`, `--missing`, `--drawerbar-bg`,
  `--cardmeta`, `--skeleton1/2`, `--toastgrad1/2`) so themes recolor everything.
  The **vault (default) theme keeps the old look** — `data-theme` unset
  or `"vault"` preserves every original variable value (the CSS file itself
  changed, but the rendered vault theme is visually identical to before).
- `html[data-theme="ledger"]`: warm archival paper (`#f4efe4` bg, `#1a1611` ink,
  oxblood `#7a2e2e` accents, brass `#8a5a1e`). Paper-toned gradients, softened shadow.
- `html[data-theme="noir"]`: true black `#050505` + champagne `#e8d9a8`.
- `@font-face` for self-hosted **Fraunces** (weights 500/600/700, `fonts/`) — serif
  now on: brand h1, card section headings, board stat numbers (`.card .val`,
  `.stat .v`), dossier titles (`.ds-head h2`), album family cards, moment text.
  Body text and tables keep the system stack (readability for Dad's viewing).
- Card hover: `translateY(-2px)` + gold border glow (latest cards + album cards;
  plain cards get the border highlight on hover-capable devices).
- New component styles: theme toggle, rain button, skeleton shimmer, stat strip,
  moment card, album cards, dossier placard, lofi pill/player bar, rain canvas,
  ambient mixer panel.
- `prefers-reduced-motion`: all animations/transitions effectively disabled;
  moment rotation and rain canvas are skipped (sound still works).

### `app.js` (presentation only, no data logic touched)
- Theme system: `setTheme()` reads/writes `localStorage.tr_theme_v1`, updates
  `aria-pressed` on the toggle, and recolors the `theme-color` meta per theme.
- Header: the "grand" chip figure now **counts up** from 0 on load (1.1s ease-out;
  skipped under `prefers-reduced-motion`).
- Board: new **"Vault at a glance" stat strip** (existing fields only:
  `value.estimated_total`, `counts.vault`, `counts.countries`, `counts.flips`,
  `photos.coins_with_photos` as % of flips, newest flip via existing `latestFlips(1)`).
- Board: new **"From the vault"** card cycling `vault.moments[]` every 12s with a

- Board: new **"Top album families"** section — top 4 of `albums_glance[]` by coin
  count as compact cards (family, coins, total, pulse). Rows whose `family` has no
  letters are skipped at render time (one malformed row exists in the current

  just refuses to render it as a family card).
- Dossier: header restyled as a **museum placard** (inner hairline frame, double
  gold rule under the header) with a new spec grid: SER · Year · Denom · Mint ·
  Est · Confidence. All existing sections/fields below are untouched.
- Skeleton shimmer in `index.html` is replaced by real content on `renderAll()`
  exactly as before; the "Awaiting photo" empty states are untouched first-class
  design elements.

- `Fraunces-500.woff2`, `Fraunces-600.woff2`, `Fraunces-700.woff2` — latin subset,
  ~35 KB each. Licensed under the SIL Open Font License (Google Fonts). No CDN —

### `favicon.svg` (new)
- Gold-coin mark (ring + dashed inner ring + gold disc) on the vault-dark rounded
  square. Per the standing rule for Pages sites (title + icons + manifest).

### `js/playlist.js` (new)
- Static JS module setting `window.TITAN_PLAYLIST` — a plain array of
  `{title, artist, url, license, credit?}`. Kept outside `data/` so the publish
  pipeline cannot clobber it. Edit by hand to swap tracks.

### `audio.js` (new) — integrated lofi player
- Autoplay attempt on boot (autoplay preference persisted in
  `localStorage.tr_lofi_autoplay_v1`, default on). Browsers block unmuted
  autoplay — the rejection is caught and a **pulsing "Tap for lofi" pill** appears.
- AudioContext resumed on first touch/pointerdown (mobile Safari).
- Play/pause, next/prev, volume slider, now-playing title/artist, track counter,
  collapsible floating bar (bottom sheet on mobile, bottom-right corner on desktop,
  all touch targets ≥44px).
- Volume (`tr_lofi_vol_v1`) and last track (`tr_lofi_track_v1`) persist.
- Dead tracks are skipped gracefully with a toast; if every track fails it stops
  and says so instead of spinning.
- CC-BY tracks (if any) show their credit line in the player UI.

### `ambient.js` (new) — rainstorm + ambient mixer
- Header **Rain** button toggles (a) a looping rain sound and (b) a full-viewport
  canvas rain-streak overlay (`pointer-events:none`, z-index below UI). Toggle off
  stops both cleanly (cancels rAF, removes resize listener, pauses audio — no leaks).
- Under `prefers-reduced-motion` the canvas animation is skipped; the sound still works.
- Enabling rain reveals the **ambient mixer panel**: Rain / Distant thunder /
  Fireplace / Night wind, each with its own toggle + volume slider.
  Shift-click the Rain button opens the mixer without toggling rain.
- Ambience state persists in `localStorage.tr_ambient_v1`; previously-on sounds
  resume on next visit (autoplay-safe: a blocked resume just stays off).
- Rain and lofi use separate `<audio>` elements → they play simultaneously.

### `sw.js`
- `BUILD` updated to `theme-refresh-2`; precache list extended with `favicon.svg`,
  the three Fraunces woff2 files, `js/playlist.js`, `audio.js`, `ambient.js`.
  (Publish regenerates the stamp — see note above.)

## Known limitations / things Joseph & Grok must know

1. **Audio is hotlinked, not self-hosted.** MP3s stream from Pixabay's CDN
   (`cdn.pixabay.com`). They will NOT work offline and could break if Pixabay
   changes URLs. Nothing was committed to the repo (no binary audio) per the
   plan. If Joseph wants offline audio, the fix is to download the MP3s into a
   `media/` folder in the repo and point the playlist/ambient configs at them —
   say the word and I'll do it (adds ~50–80 MB to the repo; Pages can serve it).
2. **`?v=theme-refresh-2` stamps must be regenerated by `publish_all.sh` on merge.**
   Do not ship the literal string to production.
3. **The malformed `albums_glance` row** (family `"$1247.71"`, ids `"$75.00"`,
   coins 2072) is hidden from the new album-family cards at render time. It still
   exists in `data/index.json` — Grok's domain to fix in the pipeline.
4. **Live-update behavior is untouched** (30s poll / 10s drip / reload-on-stamp-change
   / toast) and works identically in all three themes.
5. Autoplay: first visit will almost always show the "Tap for lofi" pill (browser
   policy) — one tap starts it, and the preference persists afterward.
6. `DRIVE_ANALYSIS.md` (untracked, repo root) is review context from this morning,
   not part of this change.
