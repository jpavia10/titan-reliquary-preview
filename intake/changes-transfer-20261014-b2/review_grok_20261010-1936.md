## GRK-S-01 · easeBack() calls pow() on a negative base (High on phones)

**Where:** wings/fx/styles-d.js:23
`float easeBack(float x){ x=clamp(x,0.,1.); float c=1.7; return 1.+(c+1.)*pow(x-1.,3.)+c*pow(x-1.,2.); }`

Callers:
- styles-d.js:82: style-comic, the starburst scale `s = easeBack(k/.18)*…`
- styles-d.js:257: style-bauhaus, `m = easeBack(clamp((f-.72)/.28,0.,1.))`

**Why it is a defect:** after the clamp, `x-1.` is always in [-1, 0], so every call except x == 1 hits `pow(negative, y)`.
GLSL ES 3.00 §8.2 says "Results are undefined if x < 0". Drivers that lower pow to `exp2(y*log2(x))`, which is common on Mali, Adreno and PowerVR, return NaN.
NaN through `s` breaks the starburst's scale and coverage for that pixel. Depending on the GPU, the burst never appears, or shows as a black or garbage block for the whole pop-in.
Desktop and ANGLE builds often fold `pow(x, 3.)` to `x*x*x`, which is why it looks fine in the lab.

**How to trigger:** force the moment on a phone, in Pulp Adventure (style-comic) or the Bauhaus theme: `TitanFX.play("style-comic"); TitanFX.moment();`.

**Smallest fix (styles-d.js:23):**
`float easeBack(float x){ x=clamp(x,0.,1.); float c=1.7, y=x-1.; return 1.+(c+1.)*y*y*y+c*y*y; }`

## GRK-S-02 · exp(-pow(signed, 2.)) everywhere (Medium on phones)

**Where (examples):**
- engine.js:127 (tap ring, every preset with `tap`)
- styles-a.js:38–40, 56, 58, 63, 283, 493, 497, 506, 514
- styles-b.js:107, 109, 177
- styles-c.js:79, 118, 119, 147–149, 181, 254, 270, 324, 329, 337
- styles-d.js:161

Counts of `pow(…, 2.)`: engine 2, styles-a 11, styles-b 3, styles-c 12, styles-d 2, plus 29 in presets.js.
The base is a signed distance such as `(ang - c0)/w` or `(uv.y - yb)/bh`, so it is negative on half the screen.

**Why:** this is the same undefined-pow rule as S-01. Most mobile compilers do special-case a literal `2.` exponent to `x*x`, so the risk is lower than S-01, but nothing guarantees it.
If a driver doesn't do it, half of each beam, band or ring disappears, or turns to NaN-black.
**How to trigger:** any of these presets on a GPU that doesn't strength-reduce pow; check the left half of the Midnight Gallery shafts (styles-a:38–40).

**Smallest fix:** add one helper to the engine prelude (engine.js:107–121), `float sq(float x){ return x*x; }`, and replace `pow(E, 2.)` with `sq(E)`.
That is a mechanical regex over the five files. It is also slightly cheaper.

## GRK-S-03 · fwidth() inside per-pixel branches (Low)

**Where:** styles-c.js:63 `if (rq < 2.15) {` encloses `fwidth(z2)` at :69, `fwidth(rq)` at :83 and `fwidth(md)` at :103. Those calls, and `lineAA`'s `fwidth` (:35–36) called from :75/:77, sit inside that per-pixel branch.
styles-c.js:112 `if (yy > 0. && uQ > .5)` encloses `lineAA` at :114.

**Why:** GLSL ES 3.00 §8.9 says derivatives are undefined in non-uniform control flow.
A 2×2 quad that straddles `rq = 2.15` or the horizon gets garbage derivatives on tile GPUs, so you see a one-pixel ring or line of wrong anti-aliasing.
The visible effect is small, because content near both edges is faint. That is why this is Low.

**Smallest fix:** compute `fwidth(rq)` and `fwidth(z2)` before the `if` at :63 (they are cheap), and pass them in. For the floor grid, compute `zf`, `xf` and `zs` and their `fwidth` before :112 with `yy` clamped to ≥ 1e-3.

## GRK-S-04 · style-particles coin map goes blank after the first play (Medium)

**Where:**
- styles-a.js:149 `var pState = { key: "" };` (module level)
- styles-a.js:151–153 `if (pState.key === key) return false; pState.key = key;`
- The engine makes a new canvas per layer (engine.js:462–464) and drops it in `killLayer` (:232) and on context loss (:340).
- On the first draw of a new layer, the engine uploads the canvas whether or not draw drew (engine.js:477 `changed || ct.n === 0`).

**How to trigger:**
1. Play Midnight Gallery (style-particles) until the coin photo has loaded.
2. Switch to any other theme, then back. Or lock the phone long enough for the WebGL context to be lost.
3. The new layer's draw returns false at :152 because `pState.key` is still "photo".
4. The engine uploads a fresh, fully transparent canvas, and the draw keeps returning false.

**Result:**
- The coin map texture is empty, so the gather loop at styles-a.js:109–113 never finds a texel and `ok` stays false.
- The "gather" moment no longer forms the coin. It only dims the dust (:128) for 8 s.
- The procedural rim fallback, which lives in the same canvas, is gone too.

**Smallest fix:** keep the key on the canvas context, which is per layer.
`if (cx.__key === key) return false; cx.__key = key;` (and delete `pState`).

## GRK-S-05 · style-splitflap still frame is an empty board (Medium, simulated)

**Where:**
- styles-b.js:135–166 `flapCanvas(c, w, h, t)` ignores the `info` argument (engine contract, engine.js:24–25: `info.still`).
- In reduced motion the engine draws the canvas once, at `t = def.still` = 4 (styles-b.js:169, engine.js:803 / :472).
- At that instant every cell's flip start is `t + r*0.12 + q*0.035` (:140). Only cell 0 has started, and it is on its first rattle letter.

**Evidence (node, the real function with a stub context):**
- Still frame glyphs: `"A"` followed by 131 blanks.
- With the clock running for 5 s, the same code shows `MEXICO        18 ON TI…`.
- So a Calm or reduced-motion user of Grand Terminal sees an empty board. The style has no readable content in its still state.

**Smallest fix (styles-b.js:135/141):** take `info`, and after the page set-up add
`if (info && info.still) for (var z = 0; z < st.cur.length; z++) st.cur[z] = st.want[z];`

## GRK-S-06 · style-vhs OSD blank on re-entry in Calm (Low)

**Where:**
- styles-a.js:464 `var vhsOsd = { sec: -1 };` (module level)
- :466–467 `var sec = info.still ? 1 : Math.floor(t); if (vhsOsd.sec === sec) return false;`

**Trigger:** in Calm, play Neon Vault, switch away, then come back. sec is 1 both times, so the new layer's canvas is never drawn and the "▶ PLAY / SP 0:00:01" OSD is missing.
In Full it is blank for up to 1 s, and it also flickers during a crossfade between two vhs layers, which share the cache.
**Smallest fix:** `if (cx.__sec === sec) return false; cx.__sec = sec;` and delete `vhsOsd`.

## GRK-S-07 · style-ascii redraws the whole grid 3×/s (Low, not measured on a phone)

**Where:** styles-b.js:47–87. At fps 3 (:91), every frame clears and redraws all lit cells of the 72×72 grid (:71–87), up to 5,184 `fillText` calls. Each cell builds a new `rgb(…)` string (:83), and then the engine uploads 512×512×4 bytes (engine.js:480).
Only the rows within ±3 % of the scan line (`near`, :76) differ between frames.
**Why:** this is per-frame main-thread canvas text work that doesn't need to be per-frame. On a mid phone, a few thousand fillText calls cost tens of ms each time, which shows as scroll jank 3 times a second.
**Smallest fix:** render the static glyph grid once into an offscreen canvas when `__lum` is built. Each frame, `drawImage` it, then redraw only the `near` rows.
Also precompute the 116 possible colour strings.

## Checked, not a finding

- **Shader compile:** all 18 presets compiled and linked under ANGLE/SwiftShader. `precision highp float` in fragment shaders is guaranteed by GLSL ES 3.00. Loops are bounded by constants (`for(int i=0;i<64;i++){ if(i>=N) break; …}` in styles-d.js:224 is fine).
  No `texture()` with implicit derivatives depends on mipmaps (the canvas textures have no mipmaps), so the `continue`/branch cases at styles-b.js:220–226 and styles-d.js:86/151 are safe.
- **Reduced motion in the engine:** canvas draws run once (engine.js:472 `ct.n === 0 || !reduced`). Moments, tap, audio, parallax and pulse are all gated on `reduced` (engine.js:229, 424–437). Motion Off stops the engine (js/app-motion.js:65).
- **motion-splash.js, can it hang or never call done()?** No.
  - Assets and fonts are capped by a 320 ms fallback that starts the clock anyway (:369).
  - `style.draw` and `style.init` throws are caught (:330, :336), so the clock can't stop on a bug.
  - `tick` calls `finishTimeline()` once t ≥ dur (:345), and `doneCalled` guards against a second call.
  - Calm draws one still frame and calls done after 1 s with a plain timeout (:351–353).
  - Motion Off never shows the splash (index.html:44 reads `TitanMotion.level()`; app-motion.js loads first, index.html:37).
  - The only case with no done() is `?splashhold` (:350), which is test-only by design.
  - In a background tab rAF pauses, so done() waits until the tab is visible. That is expected, not a hang.
- **style-layer.css:** its own transitions are switched off under reduce, Calm and Off (:232–236). I found no `animation` in this file other than `animation: none` (:72).
  I did not run a full contrast pass over every themed pair. That needs the theme tokens resolved in a browser, so I make no readability claim either way for this file.
