# Titan Reliquary — Framework Expansion Brief ("take it all the way home")

**Context.** The v3 "Midnight Museum" reskin (tr3–tr5) is a stepping stone: same app, better
suit. Joseph's directive: take creative liberty, expand beyond the current scope, perfect the
framework BEFORE he commits to final data input (the phase-2 photo scan will gather all
remaining metadata). This build must make the app *worthy* of that data entry. Target:
a presentation so considered it usurps the original Grok build — "Zuckerberg level."

**Working directory:** `~/workspace/titan-reliquary-preview/` (files: `index.html`, `styles.css`,
`app.js`, `audio.js`, `ambient.js`, `js/playlist.js`, `sw.js`). Deploys to the
`jpavia10/titan-reliquary-preview` repo / preview site. The ORIGINAL repo/site are untouched.

## Hard boundaries (do not cross)
- PRESENTATION ONLY. Never change data semantics, never edit `data/`, `version.json`, photo
  shards. `data/index.json` etc. are generated by Grok's `publish_all.sh` — read-only.
- Never delete features/screens. Additive or transformative only.
- Preserve: Logged / Photographed / Verified states, "Awaiting photo", Requests from Titan,
  shooting list, HOLD / do-not-sell rules, readability for Joseph's dad (high contrast).
- Do NOT bump `?v=` stamps, `TITAN_BUILD`, or SW `BUILD` (currently tr5) — the deploy step does that.
- New static assets live outside `data/`. No MP3 binaries committed (stream only).
- `prefers-reduced-motion`: all animation has a static fallback. Mobile-first responsive.
- Keep the lofi player (Ultralounge first) and Stormroom ambient mixer working; don't regress them.

## Workstream 1 — Atmosphere system (retire the "basic" theme toggle)
Joseph: the Vault/Ledger/Noir segmented palette-swap "is so basic" and "giving AI slop";
"don't limit yourself to what exists." Kill the palette-swap *concept*. Design an
**exhibition-lighting atmosphere system**: 2–3 atmospheres max, each a full sensory identity —
color temperature, contrast curve, surface texture/grain, glow, typography treatment, and a
suggested ambient pairing (e.g. After-Hours pairs with rain + Ultralounge). Ideas (don't feel
bound): "After Hours" (signature midnight exhibition), "Candlelight" (warm gold vault),
"Conservator" (archival-paper daylight — keeps dad-readability with a REAL concept: paper
texture, serif ledger rules, stamp motifs — NOT generic light mode). One of the three current
themes should die; pick the victim by which reads most generic. Persist choice in localStorage;
respect `prefers-color-scheme` only as a first-visit hint, never as an override.

## Workstream 2 — Phase-2-ready dossier
The dossier must be ready to RECEIVE the phase-2 photo/metadata scan gracefully. Audit every
field the scan could produce (obverse/reverse photos, grade, provenance, purchase info,
measurements, notes) and give each a designed home that renders beautifully when present and
reads as intentional "awaiting phase 2" when absent — never broken, never half-built. Add a
**dossier completeness meter**: which metadata exists vs. awaits phase 2, computed from
existing fields only (photo presence, conf, ledger fields) — frame as "awaiting phase 2",
not "missing." The flips tab already has an "Awaiting Phase 2 · 273" filter chip — make the
dossier and board echo that lifecycle language consistently.

## Workstream 3 — Photo/QC command center
Elevate the photo workflow to first-class: the shooting list, awaiting-photo states, and
shoot progress should feel like a mission board, not a buried filter. Design a dedicated
surface (section or view) that groups awaiting-photo flips for efficient shooting sessions
(by country/denomination/value priority), shows session progress, and celebrates completion.
Use existing fields only.

## Workstream 4 — Collection insights
The app should THINK about the collection, not just list it. Build an insights layer computed
from real `data/index.json` fields: value concentration (top flips by value share), age
distribution, country spread, metal breakdown, oldest/newest, "hidden gems" (low conf + high
est. value = verify first). Editorial tone, museum-placard voice. No invented data; every
number traces to a real field.

## Workstream 5 — Bulletproofing
- Keyboard: full operability (tabs, dossier, palette, player, mixer); visible focus; Esc
  closes topmost layer; a `?` shortcuts overlay.
- ARIA: roles/labels on custom controls, `aria-live` on toasts/status, focus trap in
  dossier + palette + mixer, focus restored on close.
- Offline: the SW precaches the shell; add an honest offline banner ("viewing last snapshot").
- Print: `@media print` stylesheets — a clean black-on-white printable dossier and flips
  inventory (no nav, no player, no fixed chrome). An inspector keeps paper records.

## Workstream 6 — Motion & polish pass
Audit every transition: reveal-on-scroll, count-ups, fades, the rain canvas. Make motion feel
expensive (eased, staggered, purposeful) and ensure reduced-motion kills all of it cleanly.
Fix any remaining visual roughness from the tr5 QA list (verify each fix still holds).

## Design bar
No generic AI-slop signifiers: no purple-blue gradients, no glassmorphism-for-its-own-sake,
no emoji-as-iconography, no lorem-ipsum rhythms. Typography-led, museum-placard voice,
confident whitespace. Every screen should look intentional at 390px and 1920px.
